# rolivaresia.github.io

Personal portfolio of Rodolfo Olivares (Data Analyst & Data Scientist): <https://rolivaresia.github.io/>

A single static page (`index.html`, `style.css`, `script.js`) with no frameworks or build step: animated hero, light/dark theme, experience timeline, filterable project cards with detail windows, interactive skills, and a contact section. It respects `prefers-reduced-motion` and works on mobile.
